## 6. Current Risks & Gaps

1. **Authorization hardening gaps**
   - Roadmap, insight, and github actions currently check only authentication, not project membership/role.
   - `getTaskEvents` in kanban actions does not enforce auth/role.
2. **Profile area missing** — `src/modules/profile` and `src/app/(platform)/profile` are empty.
3. **No automated test coverage** — no test suite files present in the workspace.
4. **Permissive build policy** — `next.config.ts` ignores TypeScript and ESLint errors during build.
5. **AI/provider consistency caveats**
   - Anthropic is configurable in env mapping but marked **not-ready** in provider readiness logic.
   - Gemini default chat model differs across modules (2.0 flash in `models` vs 2.5 flash fallback in roadmap/architect utilities).
6. **Realtime duplicate risk** — board may receive local `addTask` and realtime `INSERT` for the same task without explicit dedupe in `tasks-store`.
7. **Missing auth-error fallback page** — `/auth/callback` redirects failures to `/auth/auth-code-error`, which is not currently present in app routes.
